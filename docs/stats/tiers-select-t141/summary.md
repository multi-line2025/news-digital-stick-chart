## 3. 作り方
- 組：倍率 2・3・4・6・8・12・16 × 判定期間 14・28・56 日。
- 採点する行：判定期間ごとに、状態が target で、7つの倍率の判定がどれも判定不能でない行。分け方 B（学習：予言日 〜2017-12-04、確かめ：2018-01-08〜2018-12-03）。
- 段1・段2 は、判定が確定した行（週の番号で t の ceil((H + 1) / 7) 週以上前：H = 14 で 3 週、H = 28 で 5 週、H = 56 で 9 週）の判定だけで作った。
- 段4 の係数は、分け方 B の学習の行で当てはめた（ロジスティック回帰、リッジ 1）。当てはめが収まらなかったもの：無い。
- 選び方：段ごとに対数損失が最も小さい形。同じ値なら決まった順で先の形。
- 日の比率は ReadGuard（入力は t-399〜t-1、判定は t+1〜t+H）。読んだ日の範囲は 2015-03-09〜2020-11-09。網は予言日ごとに網の最後の日 < 予言日を確かめた。

## 4. 限界
- 分け方 B の確かめの期間（2018年）は、T-117〜T-134 で何度も見た期間で、段4 の候補はその結果を見て作った。
- 判定期間 56 日では、学習の行の終わり（2017-12-04）の判定期間が、確かめの期間の初め（2018-01-08）より後まで続く。分け方 B は予言日で分けていて、判定期間に依らない（T-117〜T-134 と同じ）。
- 判定期間 28 日・倍率 2・4・8 は、T-134（explore-t134r1）と同じ行・同じ作り方。
