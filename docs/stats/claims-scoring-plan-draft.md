## 1. 4段の作り方（前向きの予言に使える形）

4段とも、予言日 t の時点で入手できたデータ（t-1 以前）だけで作り、毎週前向きに全件の確率を付けて封印する（reviews/T-134.md のリードの整理）。
対象の選び方はどの段も同じ（scoring.target_status の "target"。一度跳ねたタグの扱いを含む。4章 (4)）。

| 段 | 名前 | 作り方の候補（探索で並べた形） | 前向きで固定するもの |
|---|---|---|---|
| 1 | Null | null_exp：判定が確定した行すべての (島 + 1) / (行 + 2)。null_fix：学習の行の島の割合（定数） | どちらの形か。null_fix なら学習の行の範囲 |
| 2 | Historical | タグごとの (島 + a × p0) / (行 + a)。p0 は null_exp。過去の長さ（全期間・直近52週）と縮めの強さ a（10・50・200） | 過去の長さと a |
| 3 | Naive | naive.py の7つの特徴量、ロジスティック回帰、リッジ 1 | 係数（封印済みの手順で当てはめ） |
| 4 | Digital Stick Chart | 段3 に網・波の手がかりを足したもの（探索では nbwave・chain・両方） | 足す列と係数 |

- 「判定が確定した行」：予言日 s の判定期間 s+1〜s+H が t-1 までに終わった行。H = 28 なら、週の番号で t の5週以上前。
  段1・段2 は、この行の判定だけを使う。判定期間が終わっていない行の結果は、確率に入らない。
- 段1・段2 は当てはめが要らない。段3・段4 の係数は前向きの予言の前に封印して固定する。段1・段2 の形も同じく前に封印する。
- 段2 の確率は、全体の割合へ縮めた形にする（件数の少ないタグで 0 や 1 に寄らないため）。どの形でも、行が無いタグは p0 になる。
- 段2 と段3 は入れ子でない。段3 は「size」（普段の水準の大きさ）を通して、タグごとの違いの一部をすでに持っている。
  探索では、入れ子の並び（N3 = 段3 ＋ logit(段2)、N4 = N3 ＋ 段4 の列）も並べた（3章）。

## 2. 主張1の判定の案

主張1：静かなテーマでも、1か月以内に島になる確率には、事前に予測可能な差がある。
どの案も、比べる指標を一つ（主の指標）に決め、ほかは副の指標として並べる。主の指標の候補は、対数損失の差の平均（確かめの行全体）。
判定の候補：前向きの期間の、束ねた単位（4章 (1)）でのブートストラップの 95% の範囲の上端が 0 より下。

### 案1-A：段3 対 段1 を主にする
- 内容：素朴な予測が、全タグ同じ確率より良いかを見る。
- 長所：探索で差が最も大きく、安定していた。分け方 B（2018年）の倍率 4 では、対数損失の差 −15.6%（−0.0204、範囲 −0.0222〜−0.0188）。
  倍率 2・8 でも −13.7%・−15.7%。分け方 A（2019〜2020年）でも同じくらい。検出力は高い見込み（5章）。
- 短所：差の多くは、タグごとの普段の大きさの違い（静的な違い）から来うる。段3 は size を持つので、「直近の動きが読める」ことと
  「よく報じられるタグは島になりやすい」ことを分けない。主張1の文としては満たすが、主張の中身は弱く読まれうる。
  段3 の作り方（特徴量）に依存する。

### 案1-B：段2 対 段1 を主にする
- 内容：タグごとの過去の島の割合だけで、全タグ同じ確率より良いかを見る。
- 長所：モデルが要らず、第三者がいちばん確かめやすい。「過去の割合という単純な事前の情報だけで差がある」という土台になる。
- 短所：差は形（過去の長さと a）で大きく変わる。分け方 B の倍率 4 で、−1.8%（直近52週・a = 10）〜−7.2%（全期間・a = 50）。
  倍率 8 では、範囲が 0 を含む形があった（直近52週・a = 10）。形を前向きの前に一つに決めて封印する必要があり、決め方そのものが
  問われる（4章 (3)）。検出力は案1-A より低い。

### 案1-C：段3 対 段2 を主にする（強い形）
- 内容：タグごとの過去の割合を超えて、直近の水準・季節が予測に効くかを見る。主張1を「静的な違いだけではない」と強く言う形。
- 長所：案1-A の短所（静的な違い）を差し引いた比べになる。探索では、分け方 B の倍率 4 で −9.1%〜−14.0%（段2 の形による）。
- 短所：段2 の形の決め方に依存する。主張1（土台）と主張2（分解）の境目があいまいになる。

### 案1-D：二段で判定する（案1-A を主、案1-C を副）
- 内容：主の判定は案1-A。副として案1-C を、同じ束ね方で、多重比較の調整付き（4章 (2)）で報告する。
- 長所と短所：主の検出力を保ったまま、静的な違いだけでないかを示せる。副の結果が弱いときの書き方を、前もって決めておく必要がある。

## 3. 主張2（分解）の示し方の案

主張2：予測可能性のうち、どこまでが自己履歴で説明でき、どこから先を網の構造が説明できるか。

- 示す量：上乗せ 2−1、3−2、4−3 を、どれも対数損失の差（と割合）と、束ねた単位の 95% の範囲で並べる。ブライア・較正・上位10の島も、
  副として同じ形で並べる。勝ち負け（範囲が 0 を含むか）ではなく、大きさとその幅で示す。
- 段2 と段3 が入れ子でないことの扱い（どちらかを採る）
  - 案2-a：並びのまま（1→2→3→4）。2−1 と 3−2 は足して 3−1 になるが、3−2 の中に「段2 が持つ情報を段3 が別の形で持つ分」が入る。
  - 案2-b：入れ子の並び（1→2→N3→N4）。N3 = 段3 ＋ 段2 の情報、N4 = N3 ＋ 網の列。上乗せは 2−1、N3−2、N4−N3 で、各段が前の段の情報を
    全部持つ。探索では、分け方 B の倍率 4 で N3−2 は −9.2%〜−14.2%、3−2 とほぼ同じ大きさだった。
  - 両方を並べ、主の示し方をどちらにするかを封印する案もある。
- 4−3 の大きさの目安（探索）：分け方 B の倍率 4 で、nbwave −0.05%（範囲は 0 を含む）、chain −0.29%、両方 −0.28%。
  ただし chain を足した形は上位10の島が減った（124 → 105〜106）。指標によって向きが違いうることを、前もって示し方に入れておく。
- 段4 の上乗せが小さい、または負のときも、そのまま同じ形で示す（オーナーの発言：勝っても負けても科学的に意味がある）。

## 4. 束ねた評価・多重比較・一度跳ねたタグ・判定期間

### (1) 束ねた評価（CLAUDE.md の採点計画で必ず扱うこと）
- 単位：予言日の週。週の中のタグは、同じ出来事で一緒に跳ねるので、週の中の行を独立に数えない。
- 束ね方の候補
  - 時期で束ねる：連続する ceil(H / 7) 週（H = 28 なら4週、H = 30 なら5週）を一つの束にし、束を選び直すブートストラップ
    （探索と同じ。乱数の種と回数を封印する）。判定期間が隣の束に重なる分は残るので、束を長くした感度（例：8週）も並べる。
  - 出来事で束ねる：島の割合が多い週（嵐の週。例：島の割合の上位10%）が続くまとまりを一つの束にする。または、嵐の週を除いた感度を並べる。
- 束の数が少ないとブートストラップの範囲は狭く出がちなので、前向きの週数が短い間は、束の数と、1つの束を抜いたときの差の変化
  （影響の大きい束）も並べる。

### (2) 多重比較
- 主張1：主の比べは一つ（段の組・倍率・判定期間・指標・束ね方をそれぞれ一つ）に決めて封印する。
- そのほかの倍率・指標・段の形は副とする。副は、補正の方法（例：Holm）を前もって決めるか、補正なしの記述として並べると書くか、を封印する。
- 段1・段2・段4 の形が複数あるときは、前向きの前に一つに決めて封印するか、全部を前向きに付けたうえで「主は X」と前に決めておく。
  結果を見てから形を選ばない。
- 形の決め方の候補：(a) 手法を作る期間だけで決める（探索の結果で決めるので、手法を作る期間を何度も見た偏りが残る）。
  (b) 閾値と同じく、閾値を決める期間で候補から一つ選ぶ（CLAUDE.md の閾値の決め方と同じ方式。候補は手法を作る期間のデータに触れる前に
  決める規則なので、今の探索の後で候補を作ることになる点をオーナーが確かめる必要がある）。

### (3) 一度跳ねたタグの扱い
- 4段とも、同じ対象（scoring.target_status の "target"。冷却中のタグは対象外）だけを採点する。基準値・前向きの予言と同じ選び方。
- 段2 の過去の割合も、対象の行の判定だけで数える（冷却中の週は数に入らない）。
- 全媒体で長く0が続いたテーマの印（CLAUDE.md）の扱いは、ほかの採点計画と同じものを4段に当てる（この案では決めない）。

### (4) 判定期間が未決であることの扱い
- 判定期間の候補は 14・28・56 日（candidates.HORIZON_DAYS）。CLAUDE.md の案は 30 日。主張1の文は「1か月以内」なので、
  閾値を決める期間で選んだ判定期間に、主張の文を合わせる（例：14 日なら「2週間以内」、56 日なら「2か月以内」）。
  文の合わせ方と、判定期間による束の長さ（(1)）を、前向きの前に一緒に封印する。
- 段1・段2 の「判定が確定した行」の条件も、選んだ判定期間で決まる（H 日のあとに確定）。
- 基準値の二段（素朴な成功率がおよそ2%の段と、およそ10〜15%の段）との対応：探索の確かめの行では、島の割合は倍率 4 で 2.6〜2.9%、
  倍率 2 で 12.6〜14.4%（分け方 A・B）。どの倍率を主張1・2の主にするかも、閾値の選び方と一緒に決める。

## 5. 探索の結果を検出力の見当にどう使うか

- 使い方：手法を作る期間の差の大きさと、4週束ねの範囲の幅を、前向きの週数に合わせて伸ばし縮みさせて、範囲が 0 を含まない見込みを見る。
  範囲の幅は、束の数の平方根におおむね反比例する（束は独立に近いとみなす）。分け方 B の確かめは 48 週（4週の束 12）、
  分け方 A の検証は 89 週。
- 目安（分け方 B、倍率 4、対数損失の差。半幅は範囲の幅の半分）
  | 比べ | 差 | 48週での半幅 | 26週での半幅の見当 | 13週での半幅の見当 |
  |---|---|---|---|---|
  | 3−1（案1-A） | −0.0204 | 約 0.0017 | 約 0.0023 | 約 0.0033 |
  | 2−1（全期間・a = 50） | −0.0094 | 約 0.0015 | 約 0.0020 | 約 0.0029 |
  | 2−1（直近52週・a = 10） | −0.0023 | 約 0.0016 | 約 0.0022 | 約 0.0031 |
  | 4−3（chain） | −0.0003 | 約 0.00016 | 約 0.00021 | 約 0.00030 |
  - 見当は、半幅 × √(48 / 週数) で出した。13週と26週は例で、前向きの長さは決まっていない。
- 読み方
  - 案1-A は、短い前向きの期間でも、差が探索と同じくらいなら範囲は 0 から離れる見込み。案1-B は形によって、13週では 0 を含む見込みがある。
  - 4−3 は、探索と同じ大きさでも、半年未満では範囲が 0 を含む見込みが高い。主張2 は、大きさと幅で示す形（3章）が合う。
- 限界：探索の差は、手法を作る期間を何度も見たあとの値で、段4 の形は結果を見てから選んだので、前向きでは小さくなりうる。
  分け方 B と A で差の大きさが違う比べ（例：3−2）もあり、期間による変化がある。束の数が少ないとブートストラップの範囲は狭く出がち。
  より正確な見当には、手法を作る期間の中で「前向きの長さの窓」をずらして差の分布を見るシミュレーションが使える（この案では行っていない）。
