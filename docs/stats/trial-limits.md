# 試運転の公開物の限界（T-131）

この文書は、試運転の結果（docs/stats/explore/ の要約、封印の記録、タグの一覧）を公開するにあたって、読む人が知っておくべき限界を、事実と出どころを添えて並べる。
出どころの reviews/T-XXX.md は、リードの採点と判断の記録である。各要約の中の限界の節（各要約の「限界」の章）には、その探索に固有の限界がほかにも書かれている。

## 1. 封印と時刻証明

### 1.1 seq 1・2 の X への投稿が、記録から24時間より後だった
- 事実：封印の記録 seq 1（2026-10-05T21:41:03Z）と seq 2（2026-10-06T09:58:57Z）のハッシュを X に投稿したのは、最初の投稿 seq 1-4（2026-10-07T18:24:30Z）である。記録から投稿まで、seq 1 は約44時間43分、seq 2 は約32時間26分かかった。seq 1・2 を単独で投稿したものは無い。
- 「記録を書き足すたびに、24時間以内に投稿する」は 2026-10-08 のオーナー決定で、seq 1・2 の投稿はこの決定より前である。
- seq 1・2 には OpenTimestamps の時刻証明がある。X への投稿の遅れは、この時刻証明の示す時刻を変えない。
- 出どころ：reviews/X-posts.md（「分かったこと（事実）」と 2026-10-15 の記録）。

### 1.2 seq 15 の recorded_at は、実行を始めた時刻である
- 事実：seq 15（順番4、欠けた日の一覧）の recorded_at は 2026-10-15T08:23:09Z で、実行を始めた時刻である。封印の記録への実際の追記は 10:28:34Z で、recorded_at の約2時間5分後である。追記の時刻は OpenTimestamps の時刻証明が示す。
- 記録の順序は seq で照らす。
- 出どころ：reviews/T-105.md（採点の軽-1、判定、2026-10-15 のオーナーの発言の記録）。

### 1.3 別の系列が無いことを、第三者に示せない
- 事実：手順3（ファイル一覧の取得）に進んだのは、X で封印のハッシュを公開する前だった。運営側が別の封印の記録を作って、片方だけを公開していないことを、第三者に示す手段は無い。
- 出どころ：reviews/T-013.md（2026-10-06 のオーナーの発言のあとの「リードの理解」）。

## 2. データと数え方

### 2.1 欠けた日（48日）
- 事実：手法を作る期間の区画の中で、欠けた日は48日ある。2015-05-29、2015-10-21、2015-10-22 の3日と、2020-09-28〜2020-11-17（約7週）のうちの45日である。欠けた日は、取得できたファイルの数（96本のうち72本未満）などの事前に封印した規則で決まる。一部が欠けた日は525日ある。
- 欠けた日の比率は値なしとして扱う。2020年秋の欠けは区画の終わり（2020-12-14）に近いので、手法を作る期間の最後の数回の予言の判定と、閾値を決める期間の最初の約1年の普段の水準に響きうる。影響の見込みは推測で、データで確かめていない。
- 欠けた日の一覧は封印の記録 seq 15 に入っており、件数を見たあとに規則を変えていない。
- 出どころ：docs/stats/missing-days-method.md 7章・8章、reviews/T-089.md、reviews/T-105.md。

### 2.2 区分表の記号を含む36件は数えられない
- 事実：GDELT の区分表 59,315件のうち36件は、名前に記号を含み、GKG の集計の名前の規則（封印済みのコード）に合わない。この36件は日の集計で数えられず、タグの一覧の候補に入らない。
- 規則はデータを見る前に封印したコードで決まっているので、この36件を選んで外したのではない。
- 出どころ：reviews/T-107.md（中-1 と判定）、reviews/T-098.md（「公開物の限界に書くもの」）。

### 2.3 区分表の取得は3回で、1・2回目は形の判定で止まった
- 事実：区分表の取得は合計3回行った。1回目と2回目は、取得のコードが決めた表の形の判定で止まり、区分表は保存していない。3回目で取得できた。2回目と3回目の取り直しは、オーナーの承認を得て行った。
- 出どころ：reviews/T-098.md（2026-10-15 の記録、「公開物の限界に書くもの」）。

### 2.4 区分表を取得した時機
- 事実：区分表（テーマの名前の一覧）は、除外の規則を封印したあと、順番5（タグの一覧の封印）の前に取得した。区分表は報道量のデータではなく、区分表に名前があるだけではタグの一覧に入らない。
- 出どころ：reviews/T-085.md（2026-10-15 のリードの判断 4）、reviews/T-016.md。

### 2.5 外国語の報道は数えていない
- 事実：v0 では、GDELT の翻訳の記事の流れを取得していない（2026-10-08 のオーナー決定、案a）。そのため、外国語の報道は数えていない。言語を単位にした「先に届く波」の信号は、今のデータでは測れなかった（t117r1.md 0章）。
- 出どころ：reviews/T-016.md（2026-10-08 のオーナーの発言とリードの理解）。

### 2.6 V1 と V2 の同じ名前を、同じテーマとして扱った
- 事実：正式な数え方（V1・V2 の少なくとも一方にテーマが付いた記事）では、名前の文字列が完全に一致するものを同じテーマとして扱った。V1 と V2 で同じテーマに同じ名前が使われていることは確かめていない。
- 出どころ：reviews/T-028.md（2026-10-08「正式に使う数え方」のリードの整理の「前提」）、docs/stats/counting.md（104行・314行付近）。

### 2.7 第三者が数字を確かめるには、取得をやり直す必要がある
- 事実：GDELT の元のファイルと、要約が参照する表は公開しない。Git に入るのは、データファイルのハッシュ値の一覧（マニフェスト）と封印の記録である。第三者が要約の数字を確かめるには、GDELT から同じファイルを取得し直して計算する必要がある。
- 出どころ：reviews/T-012.md（申し送り）、CLAUDE.md「データの保存」。

## 3. タグの一覧

### 3.1 手法を作る期間の全体に存在しないテーマは、v0 では扱わない
- 事実：タグの一覧の入れる規則は、手法を作る期間の全体にわたって存在するテーマだけを対象にする。期間の途中や後に生まれたテーマは v0 では扱わない。順番5（seq 17）では、テーマ 60,115個のうち 45,673個がこの条件で外れた（正式な一覧は 3,587件）。
- 出どころ：CLAUDE.md「タグの一覧」、reviews/T-004.md、reviews/T-114.md（seq 17 の reason_counts）。

### 3.2 除外の規則の漏れと、名前の衝突
- 事実：民族・人物の姓・宗教・犯罪・紛争・政治に当たる名前のテーマ（TAX_WORLDLANGUAGES・TAX_FNCACT の系統の名前など）が、タグの一覧（seq 17）に残っている。除外の規則は区分の一般の語で機械的に照合する形で、言語の分類の名前は除外の語に入れていない（docs/stats/tags-naive.md）。
- オーナーは、一覧を直さずにこのまま進め、限界として公開物に書くと決めた（2026-10-16）。
- 名前の衝突：言語の名前などのテーマは、姓や地名にも当たる。そのため、報道量の跳ね上がりが、その言語についての報道ではなく、同じ綴りの別の意味の報道によることがある。素朴な予測が見落とした島の型の一つとして、リードが挙げている。
- 出どころ：reviews/T-115.md（2026-10-16 のオーナーの決定、軽-3）、reviews/T-127.md（冒頭の記録）、t125r1.md・t127r1.md の限界の章。

### 3.3 一覧と V の先読み
- 事実：タグの一覧と、最低の報道量 V（タグを入れる規則の平均報道量の下限 A と同じ値）は、手法を作る期間の区画全体のデータで決まった（seq 17）。そのため、手法を作る期間の中の予言では、予言の対象の範囲が予言日より後のデータに依る。この期間の島の割合を、閾値を決める期間の割合とそのまま比べられない。
- 出どころ：reviews/T-115.md（中-2）、reviews/T-116.md（範囲1）。

### 3.4 2016年4月からの WB の系統の段のような上昇
- 事実：WB の系統のテーマの一部が、2016年4月から段のように上がり、2017年6月以降に戻る。報道の変化か、データ源のテーマの付け方の変化かは、データからは区別できない。
- 出どころ：reviews/T-115.md（軽-1）、reviews/T-116.md（範囲3）。

## 4. 探索の進め方

### 4.1 何度も見た期間がある（2019〜2020年の確かめ）
- 事実：T-117 で、学習（予言日が 2018-12-03 以前）と検証（2019-01-07 以降）に分けて成績を見た。その後の T-118〜T-125 でも、同じ 2019〜2020年の検証の期間を何度も見た。この期間は未見のデータではない。T-122 のあとは、2016〜2017年で学び2018年で確かめる分け方を主にしたが、2018年もその後の探索で繰り返し見ている。
- 未見のデータでの確かめは、閾値を決める期間以降になる。
- 出どころ：reviews/T-118.md（中-2、オーナーへの記録）、reviews/T-122.md、reviews/T-123.md、t123.md・t124r1.md・t127r1.md の限界の章。

### 4.2 t116.md は個々のテーマの名前を含む
- 事実：探索の要約 t116.md は、個々のテーマの名前を例として載せている。除外の規則に当たる名前と、人の姓に当たりうる名前を含む。オーナーの決定で、名前ごと公開する（2026-10-19）。T-119 以後の要約は系統の名前だけを載せる。
- 経緯：2026-10-16 のオーナーの決定（reviews/T-115.md）では、島の結果を公開するときは除外の規則の漏れに当たるテーマを伏せる、とされていた。2026-10-19 に、オーナーは t116.md を名前ごと公開すると決めた（伏せない）。
- 出どころ：reviews/T-130.md（2026-10-19 のオーナーの回答）、docs/stats/explore/README.md 3章。

## 5. 公開しないもの

- 探索の要約の PDF 版は公開しない（2026-10-18 のオーナーの判断）。PDF 版の日本語の引用文のリンクは、飛び先が誤っている（全角の文字まで含む）。公開版の要約では、リンクの形を直した。
  - 出どころ：reviews/T-129.md（採点の「気づいた点」と 2026-10-18 のオーナーの判断）。
- テーマの名前を含む表（-private.tsv）、要約が参照するほかの表、GDELT の元のファイルは公開しない。
  - 出どころ：reviews/T-130.md（オーナーの回答の「何を公開しますか？」）、CLAUDE.md「データの保存」。
