# 試運転の探索の要約（公開版の索引）

このフォルダには、試運転で統計係が出した探索の要約（summary.md）の写しを置く。写したのは T-131 である。

## 1. 試運転の位置づけ

- 使ったデータは、手法を作る期間の区画（2015-03-02〜2020-12-14）のデータだけである。区切りの日付は docs/stats/periods.md 1章にある。
- 閾値を決める期間（2020-12-15〜2023-11-06）と基準値を測る期間（2023-11-07〜2026-09-30）のデータは、試運転では使っていない。CLAUDE.md の「試運転」の手順4（最も古い期間のデータだけで試運転し、ほかの二期間のデータには手を付けない）に従った。
- ここにある要約は、手法を作る期間の中での記述と比較の探索である。モデルの形・係数・閾値・判定期間は、どの要約でも決めていない。前向きの予言でも、基準値の測定でもない。
- 公開するかどうかは、オーナーが結果を見てから決めた（試運転の手順5。reviews/T-130.md 2026-10-19 の記録）。

## 3. t116.md の要約（個々のテーマの名前を伏せた版）

- t116.md は、手法を作る期間の島の数と、代表的な島の例を並べたものである（T-115 の探索を T-116 で手直しした版）。
- 元の要約は、個々のテーマの名前（GDELT のテーマ区分の名前）を例として載せている。その中には、除外の規則から漏れた名前（民族・人物の姓・宗教・犯罪・紛争・政治に当たるもの）を含む。T-115 の決定（2026-10-16。島の結果を公開するときは、これらのテーマを伏せる）どおり、公開版では個々のテーマの名前を規則で伏せた。2026-10-19 にオーナーに確かめ直して決まった（reviews/T-130.md）。
- 伏せた規則：本文の中で、大文字・数字を下線でつないだ名前の形（下線を1つ以上含み、前後に英数字・下線が続かないもの）を、系統の名前12個（WB、ECON、SOC、ENV、TAX_FNCACT、TAX_WORLDLANGUAGES、TAX_AIDGROUPS、TAX_WORLDMAMMALS、TAX_WORLDFISH、TAX_WORLDBIRDS、TAX_WORLDINSECTS、TAX_FOODSTAPLES）と同じものを除いて、すべて「<系統の名前>_[伏せた n]」に置き換えた。系統は T-125 と同じ名前の頭の規則（TAX_ で始まる名前は2つ目の語まで、ほかは最初の語）で決め、12個に当たらないものは「その他_[伏せた n]」とした。n は本文で最初に出た順の通し番号で、同じ名前は同じ番号である。頭の書き方（TAX_、TAX_FNCACT_、TAX_WORLDLANGUAGES_ だけのもの）は伏せていない。名前ごとの判断は入れていない。
- 伏せた数：異なる名前で 119 個、出てきた回数で 305 回。名前と番号の対応表は作っていない。
- 伏せたので、t116.md の表や本文から読めるのは、島になったテーマの系統（12個に当たらないものは「その他」）と、同じ名前かどうか（番号）までである。数字は元のままである。
- T-119 以後の要約は、もともと個々のテーマの名前を載せず、系統の名前だけを載せている。
- 2〜9 の要約は、t116 と同じ予言日・対象・判定の決め方を使っている。その決め方は、各要約の 0章にも書かれている。

## 4. 写したときに変えた箇所

各ファイルの冒頭の注記にも同じことを書いた。

1. 冒頭に、引用の形（行の頭が `>`）の注記を足した。元の要約の本文にある「手で書き足していない」は、注記より下の本文についての記述である。
2. 末尾の日本語の引用文の URL を `<https://www.gdeltproject.org/>` の形にした。元の形では、自動リンクが URL の後ろの全角の文字（「）。本プロジェクトは…」）まで飛び先に含めてしまうため。引用の文言は変えていない。英語の引用文は変えていない。

t116.md だけは、このほかに個々のテーマの名前を伏せた（3章）。ほかの文と数字は、元の要約のままである。ローカルの置き場所のパスは元の要約に無かったので、置き換えた箇所は無い。t116.md・t117r1.md・t118r1.md・t119r1.md にある太字の書き方（アスタリスク2つで囲んだ部分）は、元の要約の書き方のままである。
