# 手法の方針書（下書き）：島を波の曲がり方から推定する

この文書は、予言の手法の方針を定める。変更にはオーナー＝千太郎の承認が必要。
具体的な数値や式は、ここでは決めない。統計係が過去データで作り込み、その結果をオーナーが承認する。
CLAUDE.md の決定事項と食い違う場合は、CLAUDE.md を優先する。

## 1. 基本の考え方
スティックチャートは、島そのものではなく、島の周りで波がどう曲がるかを記録した地図だった。
この手法も同じ発想を取る。予言の時点で静かなタグ（島の候補）を直接見るのではなく、
その周りに現れる信号から、そこに島がある確率を推定する。

## 2. 読む波（信号）
v0 では次の三つを読む。いずれも、予言の時点で入手できたデータだけから計算する。

### 2.1 隣の波
- GDELT では、1本の記事に複数のテーマが付く。テーマどうしが同じ記事に付いた回数から、テーマの網（共起の網）を作る。
- 静かなタグについて、網の上で隣にあるテーマの報道量の動きを集計する。隣が揃って上がり始めていれば、うねりが近づいている兆候とみなす。
- 共起の網は、予言の時点より前のデータだけで作る。網を作る期間の長さと更新の頻度は、統計係が決める。

### 2.2 先に届く波
- 同じテーマでも、一部の国・言語の報道が先に扱い、全体が後から追うことがある。
- タグごとに、国・言語別の報道量の動きを見て、全体より先に上がり始めている部分があるかを測る。
- 地域の粒度は CLAUDE.md の「データの取り扱い」に従う（標準は第一級の行政区分まで。v0 では国・言語の単位から始める）。

### 2.3 空白の形
- 隣のテーマの動きから見た「本来の報道量の期待値」と、実際の報道量の差（残差）を測る。
- 期待値より実際が小さいタグ、つまり「報じられていてもおかしくないのに、まだ報じられていない」タグを、島の候補として重く見る。
- この残差が、この手法の中心である。2.1 と 2.2 は、残差を補う信号として扱う。

## 3. 確率へのまとめ方
- 三つの信号を、ロジスティック回帰のような単純で透明なモデルで、タグごとの確率にまとめる。
- モデルの形、使う信号、係数は、手法を作る期間のデータで決め、前向きの予言を始める前に封印して固定する。
- 素朴な予測（直近の報道量・季節性・予定された行事）が使う情報も、このモデルの入力に含める。素朴な予測より良いかどうかを、三つの信号が足した分だけで測れるようにするため。

## 4. LLM の扱い
- v0 は LLM を使わない。決定的な計算だけで組む。理由は次の三つ。
  1. 同じ入力から同じ予言が出ることを、第三者が再現できるようにするため
  2. LLM は学習データに過去のニュースを含むので、過去データでの試験が汚れるため
  3. モデルの版が変わると、予言の性質が変わってしまうため
- LLM は後から「波を読む係の一人」として、別の系列で加える。その際は、LLM なしの v0 と同じタグ群で並べて予言し、LLM が足した分を比べられるようにする。
- LLM の系列を加えるときは、モデルの版・プロンプト・入力を予言ごとに封印する。

## 5. データの期間の分け方
過去データを、重ならない次の三つの期間に分ける。区切りの日付は、過去データの探索を始める前に封印する。

| 期間 | 使い道 |
|---|---|
| 手法を作る期間（最も古い） | 信号の定義、モデルの形と係数を決める。自由に探索してよい |
| 閾値を決める期間 | 判定の閾値と、二段の基準値の水準を決める |
| 基準値を測る期間（最も新しい） | 決めた閾値で、素朴な成功率と手法の成績を一度だけ測る |

- 後の期間のデータを見てから、前の期間で決めたものを変えることはしない。変える場合は、CLAUDE.md の「測り直しと公開」に従って、回数と変更点を封印して公開する。
- 信号の計算に使う過去のデータ（共起の網を作る期間など）が、期間の区切りをまたいで後ろの期間の情報を含まないようにする。

## 6. v0 の範囲
- 入れるもの：2.1〜2.3 の三つの信号、単純なモデル、素朴な予測との比較
- 入れないもの：LLM、ニュースの本文、人の判断による補正
- v0 の成績が素朴な予測を上回らなくても、それ自体を結果として記録し、公開する

## 7. 最初の割り振りの案
CLAUDE.md の「着手の順序」に従う。データの取得は、利用規約の確認とオーナーの承認の後に行う。

1. 収集係：GDELT の利用条件・速度制限・過去分の範囲・項目の確認（報告のみ。データは取得しない）
2. オーナーの承認
3. 統計係：5 の期間の区切りの案を作り、封印する手順を決める
4. 収集係：保存する項目の一覧と取得コード、テスト（ネットワークを使わない）
5. 収集係：手法を作る期間のデータの取得
6. 統計係：手法を作る期間で、三つの信号の定義と、それぞれが先行するかの探索

## 8. 未決事項

3. 先に届く波を測る単位（国か、言語か、媒体の種類か）
4. 三つの期間の具体的な区切りの日付
5. LLM の系列を加える時期と、その条件
